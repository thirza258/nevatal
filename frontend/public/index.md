# Nevatal — AI Tools Hub for Your Own API Key

Nevatal Chat is an open-source AI tools hub at https://chat.nevatal.id. It puts
seventeen focused AI tools behind one interface. You bring an API key from
OpenAI, Google Gemini or OpenRouter, and every request runs on that key: there
is no subscription and no account to create.

## Tools

- Prompt and Explainer
- Writer, Rewriter and Proofreader
- Summarizer and Copywriting
- Email Builder and Social Caption
- Idea Generator and Translator
- Sentiment Analysis
- Document AI (document Q&A)
- Image Generation
- Data Analysis and Data Formatter
- Batch Runner

## Learn
